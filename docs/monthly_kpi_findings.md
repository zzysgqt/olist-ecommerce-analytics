# 月度经营指标与趋势发现

## 分析口径

- 以 `order_purchase_timestamp` 所在月份作为需求发生月份；
- 只统计最终状态为 `delivered` 的订单；
- 商品明细和支付记录先分别聚合到一笔订单一行，再与订单表连接；
- 真实客户使用 `customer_unique_id` 去重；
- `product_value` 表示商品金额，`freight_value` 表示运费，`payment_value` 表示客户支付金额；
- 月份覆盖审计显示，严格可比区间为 2017-02 至 2018-07。

可复现查询：

- [`12_monthly_kpi.sql`](../sql/12_monthly_kpi.sql)：月度订单、客户、商品与金额指标；
- [`13_monthly_coverage_audit.sql`](../sql/13_monthly_coverage_audit.sql)：月份覆盖范围审计；
- [`14_monthly_order_trend.sql`](../sql/14_monthly_order_trend.sql)：订单数及月度环比。

## 数据事实

1. 2017-11 的已送达订单数达到 7,289 笔，为可比区间最高值，较 2017-10 环比增长 62.77%。
2. 2017-11 的客户支付金额为 1,153,528.05，同样为可比区间最高值。
3. 2017-11 的平均每单支付金额为 158.26，低于可比区间最高值 169.76（2017-04）。因此，11 月支付金额峰值主要与订单量增长同时出现，并非由最高客单价推动。
4. 2017-12 的订单数环比下降 24.37%，为可比区间最大跌幅。
5. 2018-04 至 2018-06 的订单数连续环比下降，分别为 2.93%、0.72% 和 9.63%；2018-07 环比增长 0.98%，只能视为轻微回升或暂时趋稳，尚不足以判断为强劲复苏。

## 解释边界

- 2017-11 的订单峰值与其后的回落可能与季节性或营销活动有关，但现有订单数据不能证明因果关系。
- 若要验证促销是否推动峰值，还需要活动日历、优惠券或折扣、商品价格变化、广告曝光、访问量、转化率以及未参与活动的对照数据。
- 本分析描述的是客户支付金额，不直接等同于收入或利润；数据集中没有成本、退款、平台费用和营销费用等完整财务字段。
- 2016-09 至 2017-01 及 2018-08 未覆盖完整连续自然月，不用于严格月度趋势比较。
- 已送达订单中有一笔缺少支付记录，发生在不可比的 2016-09；查询通过 `LEFT JOIN` 保留该订单并显示缺失值，没有将其当作 0 或直接删除。

## 当前业务判断

2017-11 是明显的订单规模峰值，增长更接近订单量驱动。2018 年第二季度订单量出现连续走弱，7 月仅轻微回升。后续分析应结合促销、流量、价格和成本数据，区分季节性波动、营销拉动和真实经营趋势。
