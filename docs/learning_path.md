# 学习路线

## 第一阶段：数据审计

目标：理解9张表的一行分别代表什么，并判断主键是否唯一。

- 统计各表行数与关键字段去重数；
- 检查订单状态分布及购买日期范围；
- 识别一对多关系；
- 解释为什么商品表、支付表不能直接一起汇总金额。

## 第二阶段：订单级指标层

目标：用 CTE 把明细表统一聚合到一笔订单一行。

- 商品金额、运费、商品件数和卖家数；
- 支付金额、支付次数和分期数；
- 购买、批准、发货、送达及预计送达时间；
- 使用核对字段检测订单金额与支付金额差异。

## 第三阶段：客户与复购

目标：使用窗口函数建立客户购买序列。

- 首购与复购订单；
- 月度新增客户与复购客户；
- 复购率、购买间隔和同期群留存；
- RFM 用户分层。

## 第四阶段：商品、卖家与履约

目标：把销售表现与交付质量、评价联系起来。

- 品类销售额、订单数、客单价；
- 卖家集中度；
- 延迟交付率与评价分数；
- 控制订单结构后再讨论关系，避免把相关性写成因果。

## 第五阶段：看板与项目交付

目标：从大量查询中挑选真正支持决策的指标。

- 总览、客户、商品、履约四个主题；
- 每张图只回答一个明确问题；
- README 写清口径、发现、限制和复现方式；
- 在 GitHub 中只提交代码、文档和小型结果，不提交原始大文件。
